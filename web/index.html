DocAI — Demo API Parser E-Statement Bank Indonesia

Upload PDF e-statement, dapatkan transaksi terstruktur (JSON/CSV) dengan balance-check otomatis.

⬇ Download CSV

Pilih file lalu klik Parse. Data hanya diproses di memori server demo, tidak disimpan.

Endpoint API

POST /parse   → JSON (default) atau CSV (?format=csv)
GET  /health → status + daftar bank

curl -X POST http://localhost:8000/parse \
     -F "file=@statement.pdf" \
     -F "bank=bca"

Dokumentasi lengkap: /docs (Swagger UI).
