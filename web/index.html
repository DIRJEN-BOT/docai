Contoh API

Integrasikan verifikasi penghasilan dalam hitungan baris kode

Request — cURL

# Verifikasi penghasilan dari e-statement
curl -X POST https://docaiid.pythonanywhere.com/verify-income \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@statement.pdf" \
  -F "bank=bca"
