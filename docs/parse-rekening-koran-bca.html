Cara Parse Rekening Koran BCA ke Excel, CSV, dan JSON

Tutorial otomatisasi — hentikan mengetik ulang mutasi bank.

Masalahnya

Rekening koran BCA dikirim sebagai PDF e-statement. Untuk input ke pembukuan, Excel, atau software akuntansi (Jurnal, Accurate, Kledo), datanya harus diketik ulang — rawan salah ketik dan makan waktu. Kalau Anda akuntan dengan puluhan klien, biaya ini berlipat tiap bulan.

Solusi: parse otomatis. PDF mutasi BCA → baris transaksi terstruktur (tanggal, keterangan, debit, kredit, saldo) yang siap diimpor, plus balance-check otomatis supaya saldo awal + mutasi selalu cocok dengan saldo akhir.

Contoh output

{
  "bank": "bca",
  "account_name": "PT CONTOH SEJAHTERA",
  "opening_balance": 1000000.00,
  "closing_balance": 5225000.00,
  "balance_check": "passed",
  "total_debit": 1525000.00,
  "total_credit": 5750000.00,
  "transactions": [
    { "date": "02/01/2026", "description": "TRSF E-BANKING BCA", "debit": 0, "credit": 500000, "balance": 1500000 },
    { "date": "03/01/2026", "description": "ATM WD BCA KCP THAMRIN", "debit": 250000, "credit": 0, "balance": 1250000 }
  ]
}

Output yang sama tersedia sebagai CSV (semicolon) siap import Excel: tanggal;keterangan;debit;kredit;saldo.

Fitur yang menangani "keganjilan" e-statement BCA

KasusPenanganan
PDF dikunci tanggal lahir (DOB-locked)Error jelas dengan instruksi unlock DDMMYYYY, bukan output kosong
Format angka 54,291,427.59Didukung — otomatis terdeteksi
Label DB / CR / KRDigunakan untuk menentukan arah debit/kredit
Saldo tidak balanceDitolak dengan pesan mismatch — data tidak akan lolos diam-diam

Mulai sekarang

Proyek ini open-source (MIT). Jalankan sendiri gratis:

pip install -e ".[dev]"

# CLI
docai parse --bank bca mutasi.pdf

# REST API lokal
python -m docai.api
curl -X POST http://localhost:8000/parse -F "file=@mutasi.pdf" -F "bank=bca"

Butuh versi ter-hosting dengan SLA, batch processing, dan dukungan bank lain? Hubungi kami untuk RapidAPI / enterprise access.
