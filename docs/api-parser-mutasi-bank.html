API Parser Mutasi Bank Indonesia

Ubah PDF e-statement BCA, Mandiri, BNI, BRI menjadi data terstruktur — tanpa biaya per dokumen.

Kenapa API parser bank statement penting?

Aplikasi fintech (pencatatan keuangan, credit scoring, dashboard cash-flow) butuh data transaksi bank yang rapi. Kalau parsing dilakukan manual atau dengan LLM generik, hasilnya mahal, lambat, dan tidak konsisten. DocAI memakai parsing deterministik — pola format bank yang sudah dikenal diparse langsung, sehingga COGS per dokumen praktis Rp0 dan output selalu konsisten.

Endpoint

POST /parse          → JSON (default) atau CSV (?format=csv)
GET  /health         → status + daftar bank

# Contoh request
curl -X POST https://api.docai.id/v1/statements/parse \
     -F "file=@mutasi.pdf" -F "bank=bca" \
     -H "X-RapidAPI-Key: YOUR_KEY"

Balanced check bawaan: setiap respons berisi balance_check: "passed" | "failed" plus validation_error kalau saldo tidak cocok — akuntan dapat langsung tahu data mana yang perlu diinvestigasi.
